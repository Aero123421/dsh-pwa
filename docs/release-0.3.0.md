# v0.3.0 — PWA & Mobile

DSH Web にモバイル表示を追加しました。設定画面の名前は「PWA・モバイル」（英語では PWA & Mobile）になります。

- 設定 → PWA・モバイル → モバイル表示で「自動 / オン / オフ」を選択できます。自動では幅 768px 未満で有効になり、選択はブラウザごとに保存します。
- 左のサイドバーをスライド式ドロワーに変更し、メニューボタンから開閉できます。会話部分のタップ、セッション・パネルの選択、新規セッションで閉じます。
  - すでに選択中のセッション・パネルを選び直した場合も閉じます。
- ファイル・ターミナルなどの右パネルを右から表示し、会話部分のタップで閉じられます。
- 会話・入力欄の幅、iOS の入力時ズーム、safe-area、設定ダイアログの狭い画面での配置に対応しました。
- モバイル表示ではリサイズハンドルを隠し、「動きを減らす」設定ではドロワーのアニメーションを無効にします。

パッケージ名・bundle ID・更新先は `dsh-pwa` のままです。PWA manifest・アイコン・既存の更新処理も維持します。オフにすると DSH 標準の表示に戻ります。

## 導入・更新

```sh
dsh plugin --profile web add -w github:Aero123421/dsh-pwa#v0.3.0
```

既存の GitHub ソース導入では設定画面の更新機能も利用できます。導入後は DSH を再起動してください。ローカル・tgz 導入は手動更新になります。
