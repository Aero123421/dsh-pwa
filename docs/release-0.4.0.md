# v0.4.0 — PWA & Mobile

スマホ表示を再構成し、認証付きプロキシ環境での PWA 導入経路を修復しました。

- モバイル表示を単一カラムに変更しました。会話を左右へ押し出さず、左サイドバーは会話の上に重なるオーバーレイ、右パネルは画面全幅になります。メニューは専用ヘッダーのボタンへ分離し、Escape、背面の操作無効化、閉じたときのフォーカス復帰、safe-area・visualViewport の高さに対応します。
- 設定画面の外枠・ナビゲーション・スクロール領域・閉じるボタンを狭い幅に対応させました。320px でも内容が横へはみ出しません。
- 監視対象をフレーム状態と右パネルに限定しました。ストリーミング本文を含む全会話の DOM 監視は削除しています。
- manifest へのリンクに `crossorigin="use-credentials"` を追加しました。同一オリジンでもこの指定が無いと Cookie が送られず、認証付きプロキシで画面は開けるのに manifest 取得だけ拒否される問題を防ぎます。既に開いているページではクライアント側で head を補完し、解除時は自分が変更した属性だけを復元します。
- 設定に「ホーム画面に追加」セクションを追加しました。Apple アイコンのプレビュー、manifest・PNG の到達確認、対応ブラウザのインストールボタン、Safari での操作手順、HTTPS 不足の案内を含みます。メタデータ確認の成功は OS へのインストール完了を意味しません。
- CI に Playwright によるモバイルブラウザ検証を追加しました。

パッケージ名・bundle ID・更新先は `dsh-pwa` のままです。DSH peer 範囲（`>=0.2.1-alpha.2 <0.3.0-0`）も変わりません。Service Worker・オフラインキャッシュは追加していません。

## 導入・更新

```sh
dsh plugin --profile web add -w github:Aero123421/dsh-pwa#v0.4.0
```

既存の GitHub ソース導入では設定画面の更新機能も利用できます。導入後は DSH を再起動してください。ローカル・tgz 導入は手動更新になります。

## 対応範囲

- `npm test`: 51 件成功。
- DSH `0.2.1-alpha.3` の公開パッケージ + Chromium で、配布 tgz を独立した profile に導入し 2 回起動して検証しました。
- 設定 320 / 360 / 390 / 600 / 1280px、767 / 768px の自動切り替え境界、モードの永続化と再読み込み、左サイドバー・右パネル、ライト / ダーク、動きの減少、ページ例外なしを確認しました。
- Cookie 必須の `/ui/` テストサーバーで、指定なしの manifest 取得失敗を再現し、修正後の初回表示と hot activation で取得成功を確認しました（モバイル / タッチエミュレーション）。

モバイル表示は `0.2.1-alpha.3` 公開パッケージの DOM 構造を対象にしています。iPhone / iPad / Android 実機のホーム画面追加、OS キーボード、実際の HTTPS / プロキシ環境、他のテーマプラグインとの併用は未検証です。表示が崩れた場合は設定でモバイル表示をオフにしてください。
