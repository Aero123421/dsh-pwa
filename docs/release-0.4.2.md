# v0.4.2 — PWA & Mobile

横向きの会話ヘッダーと、設定画面の細かい表示を直しました。

- 高さ 500px 以下の横向きタッチ画面では、会話ヘッダーがページの背景色で文字の上に残ります。スクロールしても吹き出しがタイトル、Standard mode、Chat / Trajectory に重なって見えません。タブは押して切り替えられます。縦向きとデスクトップのヘッダーは変えていません。
- 更新が完了したとき（導入済み、または再起動待ち）は、内部の段階名を設定画面に出しません。失敗したときは段階名とエラーコードを残します。
- 設定画面の横幅が変わると、選択中の項目がナビの表示範囲へ戻ります。
- ダイアログを開くと、開いていた左ドロワーを閉じます。
- 日本語の文言はこれまでどおり `ja` 辞書だけを登録します。言語の定義は dsh-japanese が持ち、このプラグインは `addLanguage` を呼びません。

## 導入・更新

```sh
dsh plugin --profile web add -w github:Aero123421/dsh-pwa#v0.4.2
```

GitHubソースから導入済みの場合は、設定画面の更新機能も利用できます。更新後はDSHを再起動してください。ローカル・tgz導入は手動更新です。

日本語の表示には [dsh-japanese](https://github.com/Aero123421/dsh-japanese) が必要です。
