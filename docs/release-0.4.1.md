# v0.4.1 — PWA & Mobile

スマホの会話表示と設定画面を改善しました。

- 会話ヘッダーにメニューボタンを統合し、上部バーの重複を解消しました。会話ヘッダーがない画面では上部バーを表示します。
- ヘッダーの登録は通常の別プラグインを優先します。別の表示が選ばれたときは上部バーへ切り替え、デスクトップでは登録を解除します。同じ優先度で登録すると起きるDSHの重複登録エラーも修正しました。
- 横向きのタッチ端末も自動でモバイル表示にし、左右のsafe-areaを確保しました。横長のMarkdown表はタッチ画面で横スクロールできます。
- キーボード表示時のvisual viewportの高さと位置に追従し、入力欄の下の余白を調整します。ピンチズーム中は追従を止めます。
- 設定画面の文字サイズ・色・区切り・モード切り替えを標準UIに揃え、タイトルと操作ボタンを同じ行へまとめました。ローカル導入で自動更新できない状態をエラー色にしなくなりました。

## 導入・更新

```sh
dsh plugin --profile web add -w github:Aero123421/dsh-pwa#v0.4.1
```

GitHubソースから導入済みの場合は、設定画面の更新機能も利用できます。更新後はDSHを再起動してください。ローカル・tgz導入は手動更新です。

## 検証と対応範囲

- `npm test`: 54件成功。DSH peer互換性チェック、配布JavaScriptの構文とパッケージ内容も確認しました。
- 公開DSH `0.2.1-alpha.3` / `0.2.1-rc.2` とChromiumで、配布tgzを独立したprofileに導入し、それぞれ2回起動して検証しました。
- 狭い設定画面、モード永続化、会話ヘッダー／上部バー、左右パネル、表の横スクロール、横向き、明暗、デスクトップ復帰を確認しました。別の通常優先度のヘッダー登録との併用・解除も回帰テストに追加しました。

iPhone・iPad・Android実機のOSキーボード、Safari/WebKit、ホーム画面追加は未検証です。モバイル表示はDSHの内部DOMにも依存するため、今後のDSH更新で崩れる場合は設定でオフにしてください。
